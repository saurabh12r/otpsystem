## 🚀 Features Overview

- **Firebase Core**: Initialized for multi-platform support (Android & iOS).
- **Cloud Firestore**: Real-time NoSQL database for structured data.
- **Realtime Database**: Low-latency syncing for simple data structures.
- **Cloud Messaging (FCM)**: Push notifications with automated token saving.
- **Local Notifications**: Foreground notification handling for a seamless user experience.
